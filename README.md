# حامی‌کارت | سامانه تخفیف، عضویت و خدمات سلامت (HamiCard)

> **سامانه جامع اشتراک و تخفیف خدمات پزشکی و درمانی حامی‌کارت**  
> مرجع استاندارد محصول: `BL-HAMICARD-PRD-V1` (منطبق بر PRD v1.0)  
> طراحی و توسعه داده‌شده با معماری مدرن Next.js App Router، تایپوگرافی فارسی اصیل (استعداد و وزیرمتن)، هویت بصری «لاجورد و زعفران» و پشتیبانی کامل از PWA آفلاین و موبایل.

---

## 🌟 ویژگی‌ها و قابلیت‌های کلیدی

### ۱. پشتیبانی کامل از Progressive Web App (PWA)
- **فایل مانیفست استاندارد (`/manifest.json`):** نام برند، آیکون‌های استاندارد ۱۹۲ و ۵۱۲ پیکسلی (شامل نسخه‌های Maskable)، رنگ زمینه لاجوردی (`#2a4494`) و فونت فارسی RTL.
- **سرویس ورکر هوشمند (`/sw.js`):** کش هوشمند استاتیک‌ها، فونت‌ها و تصاویر به‌همراه پوسته آفلاین اختصاصی (`/offline`) هنگام قطع اتصال اینترنت.
- **نوار شناور هوشمند نصب موبایل (Floating Mobile Install Banner):**
  - **اندروید و مرورگرهای کرومی:** شنود رویداد نیتیو `beforeinstallprompt` و نمایش دکمه «نصب اپلیکیشن حامی‌کارت» جهت باز کردن کادر استاندارد سیستم‌عامل.
  - **آیفون و سافاری (iOS / iPadOS):** تشخیص خودکار User-Agent و نمایش پاپ‌آپ راهنما با آیکون Share و دستورالعمل انتخاب «Add to Home Screen».
  - **کنترل تجربه کاربری:** قابلیت بستن بنر با ذخیره‌سازی ابطال ۳ روزه در `localStorage` و عدم نمایش مجدد پس از نصب موفق یا در حالت Standalone.

### ۲. سطوح کاربری ۵ گانه (Complete Role Surfaces)
- **بخش عمومی و بازدیدکنندگان (`/`, `/doctors`, `/plans`):**
  - صفحه اصلی با هویت بصری لاجورد و زعفران، بخش‌های معرفی طرح‌ها، نقشه خدمات و آمار سامانه.
  - دایرکتوری پزشکان طرف قرارداد با فیلتر بلادرنگ شهر، استان، تخصص و نام پزشک.
- **ناحیه کاربر و دارنده کارت (`/user`):**
  - نمایش کارت مجازی حامی‌کارت به همراه بارکد اختصاصی، شماره سریال کارت، تاریخ اعتبار طرح و مشخصات افراد تحت تکفل.
  - مشاهده تاریخچه مراجعات، ویزیت‌ها و میزان تخفیف‌های دریافت‌شده.
- **پورتال پزشکان و مراکز درمانی (`/doctor`):**
  - استعلام آنی اعتبار کارت کاربر با شماره ملی یا سریال کارت.
  - ثبت آنلاین ویزیت و اعمال تخفیف در سامانه بدون کاغذبازی.
  - مشاهده پرونده مراجعات ثبت‌شده با فیلترهای زمانی.
- **پورتال نمایندگان و بازاریابان (`/agent`):**
  - ثبت مستقیم مشتری و فروش طرح‌های عضویت.
  - مدیریت کیف پول و مشاهده ریز تراکنش‌های کمیسیون فروش.
  - ثبت درخواست تسویه حساب بانکی با احراز شماره شبا و کارت.
- **پنل مدیریت کل (`/admin`):**
  - احراز هویت دومرحله‌ای ادمین (رمز عبور + OTP) در چیدمان دوسطحی امن.
  - بررسی و تأیید درخواست‌های تسویه، مدیریت کاربران، پزشکان و طرح‌ها.
  - لاگ‌های حسابرسی (Audit Trail) و تنظیمات سیستم (`OPEN-01` تا `OPEN-18`).

### ۳. امنیت و اینوارینت‌های مالی (Financial & Concurrency Invariants)
- **`SETTLE-005` (حداکثر ۱ تسویه باز):** اعمال ایندکس یکتای جزئی (`idx_settlement_one_open_per_user`) در سطح پایگاه‌داده جهت جلوگیری از ثبت چندگانه درخواست تسویه باز به‌ازای هر کاربر.
- **`WALLET-006` (دفترکل Append-Only):** تریگرهای دیتابیس `trg_wallet_ledger_no_update` و `trg_wallet_ledger_no_delete` برای غیرقابل ویرایش و غیرقابل حذف بودن تراکنش‌های کیف پول.
- **`AUTH-011`:** کنترل نرخ درخواست (Rate Limiting) و محافظت در برابر حملات Brute-Force برای پیامک‌های OTP و ورود ادمین.
- **امنیت کلاینت و سرور:** اعمال کامل هدرهای امنیتی مدرن CSP، CSRF، `X-Frame-Options`، `X-Content-Type-Options` و پشتیبانی از اجرای امن در iframe والد ادمین.

## 🛠 پشته فناوری (Technology Stack)

| بخش | فناوری / ابزار |
| :--- | :--- |
| **فریم‌ورک اصلی** | Next.js 15 (App Router, Server & Client Components) |
| **زبان** | TypeScript 5 |
| **استایل و رابط کاربری** | Tailwind CSS, Lucide React, Radix UI Components |
| **تایپوگرافی** | فونت‌های محلی بدون CDN: Vazirmatn و Estedad |
| **پایگاه داده و ORM** | Prisma ORM (پشتیبانی دوگانه SQLite و PostgreSQL 16) |
| **احراز هویت و سشن** | JOSE / JWT، کوکی‌های `HttpOnly`، رمزنگاری کلمات عبور با bcryptjs |
| **تقویم و تاریخ** | تاریخ‌های جلالی / شمسی استاندارد با `date-fns-jalali` |
| **قابلیت PWA** | Web App Manifest v2، Service Worker آفلاین، آیکون‌های Maskable |
| **وب سرور / معکوس** | Caddy Server با TLS خودکار |

## 🚀 راه‌اندازی و اجرا در محیط توسعه

### پیش‌نیازها
- Node.js 18+ یا Bun 1.1+
- Git

### مراحل اجرا
```bash
# ۱. کلون کردن مخزن
git clone https://github.com/mytest19861986/hami-z.ai.git
cd hami-z.ai

# ۲. نصب وابستگی‌ها
npm install
# یا با bun:
# bun install

# ۳. تنظیم متغیرهای محیطی
cp .env.example .env
# مقادیر دیتابیس و کلیدهای امنیتی را بررسی کنید

# ۴. راه‌اندازی پایگاه داده و اعمال اینوارینت‌ها
npx prisma db push
# اعمال اینوارینت‌های سطح دیتابیس (Partial Index و Triggers):
# npx prisma db execute --file prisma/invariants.sql --schema prisma/schema.prisma

# ۵. بارگذاری داده‌های اولیه (Seed Data)
npm run seed
# یا: npx tsx prisma/seed.ts

# ۶. اجرای سرور توسعه
npm run dev
```

سامانه روی آدرس `http://localhost:3000` در دسترس خواهد بود.

## 🧪 تست‌های خودکار و راستی‌آزمایی E2E

مخزن شامل سناریوهای جامع تست خودکار و اعتبارسنجی یکپارچگی است:

```bash
# تست یکپارچگی اینوارینت‌های سطح دیتابیس (SETTLE-005 و WALLET-006)
node scripts/verify-db-invariants.mjs

# تست سناریوهای جامع سطوح کاربری (Surfaces E2E)
node scripts/surfaces-e2e.mjs

# تست تراکنش‌های مالی و دفترکل کیف پول (Financial E2E)
node scripts/financial-e2e.mjs

# تست تسویه‌حساب و عدم امکان ثبت همزمان (Settlement E2E)
node scripts/settlement-e2e.mjs

# تست همزمانی و مدیریت ریس کانکشن‌ها (Concurrency E2E)
node scripts/concurrency-e2e.mjs
```
