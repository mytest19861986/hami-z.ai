## داشبورد کاربر تازه‌وارد + رفع باگ استان (USER-GATE · PROFILE-FIX)
- `user-dashboard-fresh-plans-gate.png` — داشبورد کاربرِ تازه‌وارد (ثبت‌نام فقط با موبایل): بخش «طرح‌های قابل خرید» با کارت طرح‌ها (برنزی/نقره‌ای/طلایی) + بنر کهربایی و «یک دکمه» ← «تکمیل پروفایل و خرید طرح» → هدایت به پروفایل (گیت پیش از خرید)
- `user-dashboard-plans-buy-ready.png` — همان داشبورد پس از ثبت کد ملی: بنر حذف شد و دکمه‌های «جزئیات و خرید» فعال شدند (جریان عادی خرید)
- `admin-plans-ok.png` / `agent-dashboard-ok.png` — سلامت داشبورد مدیریت طرح‌ها و پنل همکار پس از تغییرات
- **رفع باگ استان:** کامپوننت `ProvinceCitySelect` بازنویسی شد — قبلاً دو callback (`onProvinceChange` + `onCityChange`) پشت‌سرهم با state کهنه صدا می‌شدند و آپدیت دوم (پاک‌شدن شهر) استانِ تازه‌انتخاب‌شده را بازنویسی می‌کرد. حالا یک `onChange({province, city})` اتمی + setForm تابعی. هر ۳ مصرف‌کننده (پروفایل کاربر، ثبت‌نام پزشک، ثبت‌نام همکار) اصلاح شد.
- **SW کش:** نسخهٔ Service Worker به `hk-v4` ارتقا یافت تا چانک‌های کهنهٔ مرورگرهای قبلی باطل شود (در dev، چانک‌ها hash محتوایی ندارند).
- **E2E:** `scripts/referral-system-e2e.mjs` دوباره ۴۰/۴۰ سبز (پس از ریست state با `scripts/reset-referral-e2e-users.ts` — دفتر مالی append-only است و فقط مانده صفر می‌شود، تاریخچه حذف نمی‌شود).
- بررسی دستی مرورگر: انتخاب استان/شهر ← ذخیره ← ریلود (ماندگاری ✓) · کنترل دسترسی نقش‌ها (کاربر عادی → /agent رد می‌شود ✓) · ورود OTP هر سه نقش ✓ · ورود ادمین با رمز ✓
